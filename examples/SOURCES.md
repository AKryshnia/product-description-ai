Они **не являются данными, официально предоставленными работодателем** для тестового задания:
если работодатель пришлёт свои два набора, для сдачи используются они.

* Страницы прочитаны 06.11.2026 в браузере (Playwright), значения перенесены из извлечённых таблиц
  и текстов разделов карточки без пересчёта; `description` — краткое изложение своими словами.
* Цены, наличие, сроки поставки, отзывы, фото и ссылки на аналоги не использовались.
* Метаданные хранятся здесь, а не во входных JSON: схема входа ради них не расширялась.

## МП3-У — `inputs/mp3-u.json`

* **Источник:** <https://www.souz-pribor.ru/product/mp3-u/> · **дата проверки:** 06.11.2026.
* **Производитель:** Манотомь (на странице — «Манотомь (Россия)»).
* **Область:** базовое исполнение манометра МП3-У. В той же карточке есть ВП3-У (вакуумметр) и
  МВП3-У (мановакуумметр) — их сведения не использованы и с МП3-У не смешивались.

### Использованные сведения

| Ключ в JSON | Раздел карточки |
|---|---|
| тип прибора | карта заказа («МП3-У — Манометр») |
| диаметр корпуса, масса, средний срок службы, межповерочный интервал, виброзащита, стекло | «Характеристики», «Краткие характеристики» |
| класс точности `1,5`, степень защиты `IP40`, конструктивное исполнение, резьба `M20x1.5-8g` | «Характеристики» + карта заказа (пометка «базовое») |
| климатическое исполнение `У2; Т2` | «Характеристики» (базовое не указано — оба значения) |
| температура окружающей/измеряемой среды | «Характеристики», дословно, **с условиями** (металлический корпус / корпус из полистирола; охладительные устройства) |
| варианты исполнения | раздел «Варианты исполнения» |
| опции по карте заказа | «Опции», «Характеристики», карта заказа; отдельным ключом, чтобы не выдавать опции за базовое исполнение |
| `description` | «Описание», «Монтаж и эксплуатация», «Правило монтажа», «Комплектация» |

### Противоречия и неопределённости (требуют уточнения)

1. **Гарантия — противоречие подтверждено.** Шапка товара: «Гарантия производителя: 12 мес.»;
   блок «Краткие характеристики»: «Гарантийный срок - 3 года.» Значение **не включено**, нужно
   уточнить у поставщика/производителя.
2. **Степень защиты «по заказу».** Таблица «Характеристики» и карта заказа — `IP54`; текст
   «Краткие характеристики» — «IP-53, IP-54», в списке модификаций присутствуют варианты с `IP53`.
   Включён только `IP54` (не противоречит ни одному разделу); `IP53` исключён до уточнения.
3. **Резьба.** `K1/2` указана только в таблице «Характеристики» и отсутствует в карте заказа —
   исключена. Базовая резьба записана на странице по-разному («М20*1,5-8g», «M20x1.5-8g»,
   «М20х1,5»); взята запись из карты заказа.
4. **Климатическое исполнение.** `У2` и `Т2` перечислены без указания базового — оба в одном значении,
   без выбора.
5. **Материал корпуса** («Сталь; Алюминиевый сплав; Ударопрочный полистирол») перечислен без привязки
   к исполнению — не включён; влияние материала сохранено только в условиях температуры окружающей среды.

### Исключено и почему

* гарантия (п. 1), `IP53` (п. 2), `K1/2` (п. 3);
* материалы корпуса, пружины, держателя, механизма — перечни вариантов без привязки к базовому исполнению;
* диапазоны измерений и единицы — определяются модификацией (в JSON не выбирались);
* демпфер — наличие зависит от диапазона и оговаривается при заказе;
* аналоги других производителей, номер Госреестра, «сертификат дилера» — не требуются либо нуждаются в документе;
* «область применения: все отрасли промышленности…» — общая рекламная формулировка;
* цены, остатки, сроки поставки, отзывы, акции — изменяющиеся коммерческие сведения.

### Результат генерации

`outputs/gigachat-live-catalog/mp3-u.result.{json,md}`, метрики — `run-summary.json` (реальный GigaChat,
`GigaChat-2-Pro`). Проверка вручную: значения в тексте совпадают с JSON; условия температуры сохранены;
гарантия и спорные сведения не упомянуты; коммерческий блок без выдуманных задач.

**Найдено при проверке и исправлено в сервисе:**
1. Первая генерация обобщила условие: «от −50 до +60 °C в зависимости от материала корпуса» (−50…+60 — только для
   металлического корпуса). Проверка чисел это не видит, поэтому в промпт добавлено правило переносить значения
   только вместе с условием; повторная генерация сохранила оба варианта.
2. «Технологические процессы» и «мониторинг» в коммерческом блоке считались подтверждёнными, потому что во входе
   есть «технологическая черта на шкале». Проверка отраслей и процессов теперь сопоставляет фразу, а не основу слова;
   добавлен тест на этом реальном случае.

Остаётся ограничением: искажение условий, при котором все числа присутствуют во входе, автоматически не ловится.
