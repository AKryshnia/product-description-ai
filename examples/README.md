# Примеры

## Входные данные (`inputs/`)

| Файл | Происхождение | Назначение |
|---|---|---|
| `01-manometer-dm02-from-task.json` | Иллюстративный пример из текста тестового задания, без изменений (описание там обрезано многоточием). | Базовый сценарий. |
| `02-demo-digital-thermometer.json` | **Демонстрационные данные**, придуманы для этого репозитория. Прибора и производителя не существует. | Богатый набор: числа, единицы, интерфейс, степень защиты. |
| `03-demo-incomplete.json` | **Демонстрационные данные.** | Неполный вход: нет производителя и описания, одна характеристика пуста. |
| `04-demo-prompt-injection.json` | **Демонстрационные данные.** | Описание содержит попытку внедрения инструкций. |
| `mp3-u.json` | Реальная публичная карточка «СОЮЗ-ПРИБОР»; происхождение, противоречия и исключения — в [`SOURCES.md`](SOURCES.md). Не данные работодателя. | Базовое исполнение и опции, условия применения, спорная гарантия. |
| `testo-608-h1.json` | Реальная карточка «СОЮЗ-ПРИБОР», из присланного пакета без изменений; **по странице не сверена** ([`SOURCES.md`](SOURCES.md)). Не данные работодателя. | Раздельные характеристики влажности и температуры, условия погрешности. |
| `ifn-300.json` | То же (пакет, не сверено). | Несколько видов сопротивления и диапазонов, токи КЗ. |
| `vit-1.json` | То же (пакет, не сверено). | Производитель на странице не назван (`manufacturer` пуст). |

Исходные данные двух реальных приборов в задании не приложены, поэтому характеристики файлов 02–04
не относятся ни к каким реальным приборам или производителям и не должны попадать в каталог.
Когда появятся реальные данные, достаточно отправить их в `POST /generate` — менять код не нужно.

## Результаты (`outputs/`)

`outputs/gigachat-live/` — **реальные** ответы GigaChat (дата, модель и метрики прогона — в
`run-summary.json`), получены командой `python scripts/live_check.py`.
`outputs/gigachat-live-catalog/` — реальные ответы GigaChat по данным реального каталога.
Результаты мокированных тестов здесь не хранятся: они не являются ответами GigaChat.
