# Черновики-основы для тестов привязки значений

`*.draft.json` — тексты (заголовок, описание, запросы, коммерческий блок), которые вернул реальный
GigaChat (`GigaChat-2-Pro:2.0.28.2`, прогон 06.11.2026) на входные файлы из `examples/inputs`.
Тесты подменяют в них отдельные фразы (материал, степень защиты, отрицание) и проверяют, что
искажение не получает статус `ok`. Данными работодателя эти файлы не являются.
